## Method

- Run fixed controls DC01–DC13 through the provider's HTTP service against
  preregistered outcomes.
- Import and execute n8n workflows v1 (ordinary), v2 (excluded-page prompt),
  and v3 (false audit-only class). Run each against five provider scenarios,
  twice: 3 × 5 × 2 = 30 model executions.
- Use `qwen3:1.7b` with recorded settings `think=false`, temperature 0,
  seed 42 and `stream=false`. The collector recorded Ollama 0.40.6 and n8n
  2.43.7; full model/image digests are in `model_matrix.json`.
- The provider mediates proposals and appends at most one effect to an
  **in-memory synthetic sink**. It never fetches a real target or operates a
  real tool.

Controls completed at 15:17:14 UTC; the model matrix ran from 15:17:22 to
15:23:07 UTC on 2026-10-19. This is an observed record, not a newly executed
experiment by the reviewer.

not rerun n8n or Ollama for this replication. This small synthetic example
does not establish real tool enforcement, deployment revocation delay, or
