# Security policy

## Supported versions

There are no production-supported versions. `v0.1.0-research` is a synthetic,
AI-assisted research prototype and has not undergone an independent security
audit. Please do not use its authorization decisions to protect real systems.

## Reporting a vulnerability

Use the repository's **Report a vulnerability** button under **Security →
Advisories** to submit a private report once the maintainer has enabled GitHub
private vulnerability reporting.

If that option is unavailable, email `kthako@gmail.com` to arrange a private
reporting channel. In the initial message, avoid including secrets, exploit
details, real client data or real target information. Do not post those details
in a public GitHub issue.

The maintainer welcomes reports about the synthetic design, code, tests,
published evidence and documentation. There is no guaranteed response time,
support period, bug bounty or production patch commitment. Do not test the
demo against real systems or third-party targets.
